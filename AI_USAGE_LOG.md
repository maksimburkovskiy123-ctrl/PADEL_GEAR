# Отчет об использовании ИИ

## КТ-1. Концепция проекта

- **Задача:** изучить методические материалы и подготовить концепцию информационной системы для подбора ракеток для падела.
- **Что предложил ИИ:** формулировку проблемы, целевую аудиторию, состав ограниченного MVP, обоснование стека Python/FastAPI/SQLite/SQLAlchemy/Jinja2 и вариант объяснимого weighted scoring без ML.
- **Что использовано:** структура и формулировки документа `KT1_CONCEPT.md`, решения и статус в `PROJECT_STATE.md`.
- **Как проверено:** требования сверены с прикрепленными DOCX и PPTX; проверено наличие четырех обязательных частей КТ-1 — проблема, ЦА, MVP и технологический стек. Код на этом этапе не создавался.

## Корректировка КТ-1 и КТ-2

- **Задача:** сократить КТ-1 до формата методички и подготовить следующий этап проекта.
- **Что предложил ИИ:** краткую структуру КТ-1 и сценарии для каталога, карточки, сравнения и персональной рекомендации.
- **Что использовано:** обновленный `KT1_CONCEPT.md` и новый `KT2_REQUIREMENTS.md`.
- **Как проверено:** КТ-1 сверена с обязательными разделами шаблона; КТ-2 составлена по схеме «сценарии использования → функциональные требования». Код не создавался.

## КТ-3. Экраны, навигация и прототип

- **Задача:** спроектировать основные экраны, навигацию и ключевые пользовательские пути.
- **Что предложил ИИ:** структуру из шести экранов и простой интерактивный прототип на HTML, CSS и vanilla JavaScript.
- **Что использовано:** `KT3_DESIGN.md` и `outputs/KT3_PROTOTYPE.html`.
- **Как проверено:** проверены переходы между главной, каталогом, карточкой, сравнением, анкетой и результатами; демонстрационные данные явно отделены от будущего каталога.

## Разработка MVP

- **Задача:** реализовать рабочую версию по утвержденным требованиям без React и сложной архитектуры.
- **Что предложил ИИ:** FastAPI-приложение с серверными Jinja2-шаблонами, SQLAlchemy-моделью `Racket`, SQLite, ручным seed-каталогом из 15 реальных моделей и объяснимым weighted scoring.
- **Что использовано:** каталог, фильтры, карточки, сравнение, анкета, рекомендации, тесты, README и зафиксированные зависимости.
- **Как проверено:** данные сверены по страницам Babolat, Bullpadel и All For Padel; `python -m pytest -q` — 7 тестов пройдено; `compileall` пройден; Uvicorn вернул HTTP 200 для главной, каталога и рекомендаций.

## Тестирование MVP

- **Задача:** проверить основные сценарии и граничные случаи после разработки.
- **Что предложил ИИ:** расширить автоматические проверки фильтров, сравнения, несуществующих моделей, диапазона оценок и целостности каталога.
- **Что использовано:** дополнительные тесты и документ `TEST_REPORT.md`.
- **Как проверено:** `python -m pytest -q` — 12 тестов пройдено; `compileall` пройден; семь основных HTTP-маршрутов через Uvicorn вернули `200`.

## Подготовка README и GitHub

- **Задача:** подготовить проект к публикации и проверке преподавателем.
- **Что предложил ИИ:** структурированный README, `.gitignore`, GitHub Actions workflow для pytest и инструкцию первого push.
- **Что использовано:** обновленный `README.md`, `GITHUB_SETUP.md` и `.github/workflows/tests.yml`.
- **Как проверено:** проверены команды запуска и тестирования; служебные файлы, база SQLite и загруженные материалы добавлены в `.gitignore`.

## Публикация на GitHub

- **Задача:** загрузить проект в репозиторий пользователя от его GitHub-аккаунта.
- **Что предложил ИИ:** безопасную загрузку через авторизованную веб-сессию без передачи пароля или токена в чат.
- **Что использовано:** репозиторий `maksimburkovskiy123-ctrl/PADEL_GEAR`, ветка `main`, проектные файлы и workflow.
- **Как проверено:** дерево репозитория содержит исходники, тесты, документацию и прототип; GitHub Actions `Tests #2` завершился со статусом `Success`.

## Перенос и восстановление незавершенной работы, 2026-09-12

- **Задача:** восстановить проект из общей сессии и продолжить с последнего фактического состояния.
- **Что использовано:** локальная копия репозитория `PADEL_GEAR` и незапушенные исправления предыдущей сессии.
- **Восстановлено:** валидация анкеты, фильтр веса, сохранение сравнения в cookie, удаление и замена моделей, сохранение фильтров, исправление трех цен, журнал источников и регрессионные тесты.
- **Как проверено:** `python -m pytest -q` — 45 тестов пройдено; `python -m compileall -q app tests` и `git diff --check` завершились без ошибок. Изменения пока не отправлены в GitHub.

## Завершение MVP, 2026-09-12

- **Задача:** закончить MVP до перехода к 3D.
- **Что использовано:** исправленная мобильная сетка карточек рекомендаций и текущие маршруты приложения.
- **Как проверено:** 45 тестов, compileall и diff check; сквозные HTTP-проверки основных страниц; визуальная проверка каталога, сравнения и рекомендаций на мобильной и десктопной ширине.
- **Результат:** MVP готов к публикации обновлений. 3D отложено до отдельного этапа.

## Подготовка передачи преподавателю, 2026-09-12

- **Задача:** сделать запуск проекта с диска максимально простым.
- **Что использовано:** `START_APP.bat` для Windows, `OPEN_APP.bat` для повторного открытия браузера, `start_app.sh` для macOS/Linux и `TEACHER_GUIDE.md`.
- **Как проверено:** shell-скрипт проверен синтаксически; запуск с чистой временной SQLite-базой установил зависимости и запустил Uvicorn на `127.0.0.1:8000`.
