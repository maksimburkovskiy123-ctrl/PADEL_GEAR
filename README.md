# Padel Match

Учебный MVP информационной системы для подбора ракеток для игроков в падел.

## О проекте

Выбор ракетки затруднен большим количеством моделей и технических характеристик. Padel Match объединяет каталог реальных моделей, фильтрацию, сравнение и короткую анкету. После анкеты система показывает несколько подходящих моделей и объясняет результат.

Проект разработан в рамках индивидуального цифрового проекта. В MVP рассматриваются только ракетки. Регистрация, покупки, отзывы, автоматическое обновление цен, другая экипировка, сложное ML и 3D не входят в текущую версию.

## Возможности MVP

- каталог из 15 реальных моделей Adidas, Babolat и Bullpadel;
- карточка модели с характеристиками, ориентировочной ценой и источником;
- фильтрация по бренду, уровню, форме, группе баланса и условной группе веса;
- сравнение от двух до трех моделей с сохранением выбранных моделей между страницами;
- анкета без регистрации;
- топ-5 рекомендаций;
- текстовое объяснение причин рекомендации;
- автоматические тесты основных сценариев и граничных случаев.

## Технологии

- Python;
- FastAPI;

React, TypeScript и Node.js не используются: серверного HTML достаточно для небольшого учебного MVP.

## Запуск локально

Требуется Python 3.11 или новее.

1. Установить зависимости:

```bash
python -m pip install -r requirements.txt
```

2. Запустить приложение:

```bash
uvicorn app.main:app --reload
```

3. Открыть `http://127.0.0.1:8000`.

При первом запуске создается `data/padel.db`, после чего каталог заполняется из `app/seed.py`.

## Запуск с диска

Для демонстрации преподавателю в Windows достаточно открыть `START_APP.bat`. При первом запуске скрипт создаст окружение, установит зависимости и откроет приложение в браузере. Подробная инструкция находится в `TEACHER_GUIDE.md`. Для уже запущенного сервера есть `OPEN_APP.bat`.

## Тестирование

Запуск автоматических тестов:

```bash
python -m pytest -q
```

Проверка синтаксиса:

```bash
python -m compileall -q app tests
```

Последний результат: **45 тестов пройдено**. Подробности находятся в `TEST_REPORT.md`.

## Рекомендательный алгоритм

Машинное обучение не используется. Для каждой модели рассчитывается оценка от 0 до 100:

- уровень игрока — 30%;
- стиль игры — 25%;
- главный приоритет — 20%;
- предпочтительный вес — 15%;
- баланс — 10%.

Уровень и стиль имеют больший вес, потому что задают основное соответствие ракетки пользователю. Вес и баланс уточняют выбор. Сумма весов равна 100%. Алгоритм находится в `app/services/recommender.py`, его веса и порядок сортировки проверяются тестами.

Для числового баланса в миллиметрах используются три группы: низкий, средний и высокий. Это нормализация для алгоритма, а в карточке сохраняется исходное значение из источника.

## Данные

Характеристики и цены вводятся вручную. В каталоге сохранена ссылка на страницу источника для каждой модели. Использованы страницы производителей Babolat и Bullpadel, а также официальный магазин All For Padel для моделей Adidas. Цены являются ориентировочными и могут изменяться. Основания проверки и правила нормализации записаны в `data/SOURCES.md`.

## Структура проекта

```text
  database.py                # подключение SQLite и SQLAlchemy
  models.py                  # модель Racket

  templates/                 # Jinja2-шаблоны

TEST_REPORT.md              # отчет о тестировании
```
