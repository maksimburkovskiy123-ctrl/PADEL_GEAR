# КТ-3. Экраны, навигация и прототип

## 1. Основные экраны

### Экран 1. Главная страница

Назначение: кратко объяснить пользу системы и направить пользователя к каталогу или подбору.

Основные элементы:

- название и краткое описание сервиса;
- кнопка «Пройти подбор»;
- кнопка «Открыть каталог»;
- краткая последовательность: анкета → сравнение → рекомендация.

### Экран 2. Каталог ракеток

Назначение: показать доступные модели и помочь сузить выбор.

Основные элементы:

- список карточек ракеток;
- фильтры по бренду, уровню, весу, балансу и форме;
- кнопка перехода к карточке;
- кнопка добавления в сравнение;
- переход к экрану сравнения.

### Экран 3. Карточка ракетки

Назначение: показать подробную информацию об одной модели.

Основные элементы:

- бренд и название;
- изображение или визуальный блок модели;
- основные характеристики;
- ориентировочная цена;
- источник данных;
- кнопка добавления к сравнению.

### Экран 4. Сравнение

Назначение: сопоставить две или три выбранные модели.

Основные элементы:

- названия выбранных моделей;
- таблица общих характеристик;
- цена и назначение;
- удаление модели из сравнения;
- возврат в каталог.

### Экран 5. Анкета подбора

Назначение: получить данные о пользователе для расчета рекомендаций.

Основные элементы:

- индикатор текущего шага;
- уровень игрока;
- стиль игры;
- предпочтения по контролю, мощности, маневренности, весу и балансу;
- кнопки «Назад» и «Продолжить».

### Экран 6. Результаты подбора

Назначение: показать наиболее подходящие модели и объяснить результат.

Основные элементы:

- список лучших моделей;
- итоговая оценка соответствия;
- характеристики модели;
- список причин рекомендации;
- переход к карточке и сравнению.

## 2. Навигация

Основная навигация доступна в шапке сайта:

```text
Главная ─┬─> Каталог ─> Карточка ─> Сравнение
         └─> Подбор ─> Результаты ─> Карточка / Сравнение
```

Дополнительные переходы:

- из карточки можно вернуться в каталог;
- из сравнения можно вернуться в каталог;
- после завершения анкеты пользователь попадает на результаты;
- из результатов можно открыть карточку рекомендованной модели.

Регистрация и личный кабинет в навигации отсутствуют, так как не входят в MVP.

## 3. Покрытие ключевых сценариев

### Сценарий поиска и сравнения

Главная → Каталог → фильтр → карточка → добавить 2–3 модели → Сравнение.

### Сценарий получения рекомендации

Главная → Подбор → уровень и стиль → предпочтения → Результаты → причины рекомендации → Карточка.

### Сценарий просмотра модели

Каталог → Карточка → характеристики и источник данных → возврат в каталог или сравнение.

## 4. Прототип

Интерактивный прототип находится в файле `outputs/KT3_PROTOTYPE.html`.

Он позволяет пройти основные пути без backend и базы данных: перейти между экранами, отфильтровать демонстрационные карточки, открыть карточку, выбрать модели для сравнения и пройти анкету до экрана рекомендаций. Демонстрационные данные не являются частью каталога реальных ракеток.
