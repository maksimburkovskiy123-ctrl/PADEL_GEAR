# Как запустить проект преподавателю

## Windows

1. Скопировать папку проекта с диска на компьютер.
2. Дважды открыть `START_APP.bat`.

После запуска откроется браузер с адресом `http://127.0.0.1:8000`. Черное окно сервера нужно оставить открытым во время показа. Чтобы остановить приложение, закройте это окно.

При первом запуске требуется интернет: скрипт создаст локальное окружение и установит зависимости. После этого интернет для обычного запуска не нужен.

Требование: Python 3.11 или новее. Если Python не установлен, его нужно один раз установить с [python.org](https://www.python.org/downloads/), включив пункт `Add python.exe to PATH`.

Если сервер уже запущен, `OPEN_APP.bat` просто откроет страницу приложения в браузере.

## macOS и Linux

Открыть терминал в папке проекта и выполнить:

```bash
chmod +x start_app.sh
./start_app.sh
```

## Что находится в проекте

- `app/` — FastAPI-приложение, шаблоны и стили;
- `data/SOURCES.md` — источники и правила проверки каталога;
- `tests/` — автоматические тесты;
- `KT1_CONCEPT.md`, `KT2_REQUIREMENTS.md`, `KT3_DESIGN.md` — материалы контрольных точек;
- `outputs/KT3_PROTOTYPE.html` — прототип КТ-3;
- `PROJECT_STATE.md` — состояние проекта;
- `TEST_REPORT.md` — отчет о проверке.

Файл базы `data/padel.db` создается автоматически при первом запуске и не требуется для передачи: каталог заполняется из `app/seed.py`.
