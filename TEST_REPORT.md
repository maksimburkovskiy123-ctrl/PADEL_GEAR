# Отчет о тестировании MVP

## Результат

Дата проверки: 2026-09-12.

Автоматические тесты: **45 пройдено, 0 ошибок**.

Дополнительно приложение запущено через Uvicorn. HTTP `200` получен для главной страницы, каталога, карточки, сравнения, анкеты, рекомендаций и CSS-файла.

После исправления мобильной сетки визуально проверены каталог, сравнение и рекомендации на мобильной и десктопной ширине. Текст и кнопки рекомендаций больше не сжимаются в узкую колонку.

## Команды проверки

```bash
python -m pytest -q
python -m compileall -q app tests
uvicorn app.main:app --reload
```

В текущем окружении тестовая база запускалась во временном файле SQLite, потому что рабочая папка блокирует SQLite-файлы. На обычной локальной файловой системе приложение использует `data/padel.db` согласно README.

## Ограничения

- не проводилось нагрузочное тестирование;
- не проверялись разные браузеры и специальные средства доступности;
- цены остаются ориентировочными и вводятся вручную;
- реалистичные изображения и 3D-модели ракеток пока не добавлены; текущие силуэты являются CSS-заглушками.
